# Guía de CupidoDigital

Editá la presentación del estudio en `index.html`, `styles.css` y `script.js`. El formulario envía a `/api/contact` y `tests/contact.test.js` comprueba su manejo en `_worker.js`.

Corré `pnpm run check`, `pnpm test` y `pnpm run build`. Cuando cambien rutas, comprobá la versión bajo la subcarpeta `CupidoDigitttal` de GitHub Pages.

Consultá los pasos de publicación en [el flujo de GitHub Actions](.github/workflows/cloudflare.yml). Para verificar los dos sitios publicados, seguí [la guía de publicación](docs/PUBLICACION.md).
